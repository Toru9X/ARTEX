# Wordfence (WordPress WAF)

### Detection Signals
| Signal | Where |
|--------|-------|
| Block page: "Generated by Wordfence" | 403 response body footer |
| Block page: "A potentially unsafe operation has been detected" | Response body |
| Block page: "Your access to this site has been limited" | Response body |
| `wfvt_` cookie prefix | Wordfence visitor tracking |
| `wordfence_verifiedHuman` cookie | Human verification cookie |

### Bypass Strategy
- **Recommended tool**: Burp + Playwright. WordPress-specific WAF.
- **Key insight**: Wordfence free vs premium have VERY different rule sets. Free = basic regex. Premium = real-time threat intel.
- **WordPress-specific**: Focus on wp-admin, wp-json, xmlrpc.php. Wordfence rules are WordPress-context-aware.
- **IP whitelist**: Wordfence often trusts XFF header → try `X-Forwarded-For: 127.0.0.1`

### XSS Bypass

```
# Wordfence blocks: standard XSS in params, but may miss stored XSS in WP context

```

### SQLi Bypass
```
sqlmap --tamper=space2comment,between,charencode -u URL

# wp-json API often less protected than wp-admin:
/wp-json/wp/v2/users/?per_page=100&offset=0
/wp-json/wp/v2/posts/?per_page=100&status=draft

# Manual:
' /*!50000UNION*/ /*!50000SELECT*/ 1,2,3--
```

### Rate Limiting
- Free: 240 req/min default (configurable).
- Premium: more aggressive + real-time IP reputation.
- Block: 403 + "Rate limited" page.
- Recovery: wait or change IP.
